# Proyecto de Estudio e Investigación
Este repositorio recopila la documentación académica y los scripts en SQL del trabajo práctico integrador de la cátedra Bases de Datos I.
## Presentacion del proyecto
El proyecto consiste en diseñar la base de datos de un sistema de ventas para una tienda física especializada en computación, dedicada a la comercialización de PCs pre-armadas, notebooks y Pcs All In One.
El local atiende tanto a clientes minoristas como a pequeñas empresas que necesitan equipamiento informático. El sistema debe permitir gestionar el catálogo de productos y su stock disponible, registrar clientes y usuarios, procesar ventas (detallando productos, cantidades y precios) y admitir distintos métodos de pago.
